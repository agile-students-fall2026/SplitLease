# SplitLease
SplitLease is a communal financial and physical asset ledger designed for shared apartments. The platform acts as a centralized dashboard which helps track shared household assets, log shared expenses, calculate depreciation, manage move out buyouts, and establish roommate protocols. 

## Product Vision Statement
To provide roommates with a transparent, unified system for managing shared expenses and physical assets, eliminating financial ambiguity during a lease term and simplifying the equitiy distribution prodcess during move-outs during shared residential or commercial space.

**Minimum Viable Product**
The MVP provides the essential function to organize shared spaces.

*   **Space & Member Management**
    *   **Feature:** Secure user authentication (Login/Registration).
    *   **Feature:** Create a new shared space (Household) or join an existing one using an auto generated invite code.
    *   **Feature:** Manage  members and user profiles, including preferred payment links.
*   **Financial Tracking**
    *   **Feature:** Log new shared bills and operating expenses.
    *   **Feature:** View monthly expense summaries detailing amounts paid and amounts due per member.
*   **Asset Ledger**
    *   **Feature:** View a centralized list of shared physical assets (e.g. apartment furniture, studio equipment).
    *   **Feature:** Add new physical assets with associated costs and descriptions.
*   **Co-tenant Protocols**
    *   **Feature:** Propose new household rules or agreements.
    *   **Feature:** Review, approve, or request changes to pending protocols across the group.
